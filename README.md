# Paper Explainer · 论文讲解手册

一个中文 Codex skill：阅读你提供的论文正文和支持材料，生成可直接用于理解与讲解的 Markdown 手册。重点是把论文从第一组图到最后一组图的论证线讲清楚，并逐个解释子图的坐标、颜色、数据、能支持的结论及解释边界。

## 使用

将本仓库放入个人 Codex skills 目录中的 `paper-explainer` 文件夹。随后上传论文和支持材料，直接说：

> 请读这篇论文和补充材料，生成中文论文讲解手册。逐图解释每个子图的横纵坐标、颜色、数据点，以及它支持和不能支持的结论。

也可以显式调用：

> 使用 `$paper-explainer` 阅读我上传的论文和支持材料，生成讲解手册。

只有明确要求生成讲解文稿、手册或汇报讲稿时才适用；普通论文问答、摘要和文献综述无需套用该结构。

## 手册内容

1. 一句话概括全文工作，并给出准确的形象比喻。
2. 用“问题 → 应对 → 结论”串起论文。
3. 只有能确认实质贡献时才写一句话创新点。
4. 说明全部图组如何连成全文论证线。
5. 逐组、逐子图解释图形元素与关键数据。
6. 对每张图按“作者想回答什么 → 怎样读图 → 能支持什么 → 还不能说明什么”讲解。
7. 同时在对话中呈现并保存 Markdown 文件，附可回查的图号、章节或页码。

无法辨认的图形元素或缺失材料会明确标注，不猜测数值和图意。
